# اذان‌گو (AzanGo)

اپلیکیشن اندروید برای اوقات شرعی و پخش اذان — فارسی، راست‌چین، با رابط بزرگ و ساده برای سالمندان.
رابط: HTML/CSS/JS داخل Capacitor 6 · بخش‌های حساس اندروید: Kotlin.

## وضعیت صادقانه پروژه (حتماً بخوانید)

| مورد | وضعیت |
|---|---|
| موتور محاسبه اوقات (`www/js/praytimes.js`) | اجرا و با `npm test` آزمایش شده (ترتیب اوقات، تغییر با تاریخ، فصل‌ها) |
| سینتکس JavaScript | بررسی شده |
| اسکریپت الحاق Kotlin به پروژه Capacitor | روی یک پروژه شبیه‌سازی‌شده آزمایش شده |
| **کامپایل Kotlin / ساخت Gradle / فایل APK** | **انجام نشده.** محیط من اینترنت و Android SDK نداشت، پس APK تحویل نمی‌دهم و ادعای تست روی گوشی هم ندارم |
| رفتار روی گوشی واقعی (آلارم، پخش، اعلان) | **آزمایش نشده**؛ لطفاً مطابق بخش «چک‌لیست تست» امتحان کنید |

## ساختار

```
AzanGo/
├─ www/                  رابط کاربری (index.html, css/, js/)
│   └─ js/praytimes.js   محاسبه اوقات؛ cities.js شهرها؛ app.js صفحه‌ها؛ native.js پل به Kotlin
├─ native/kotlin/        AzanPlugin, AzanCore, AzanReceiver, AzanService, BootReceiver, MainActivity
├─ native/manifest_*.xml مجوزها و کامپوننت‌هایی که به AndroidManifest اضافه می‌شوند
├─ tools/                patch_android.py (الحاق Kotlin)، test-praytimes.js
├─ capacitor.config.json · package.json · setup.sh · build-apk.sh
```
پوشه `android/` عمداً داخل پروژه نیست؛ Capacitor آن را با نسخه‌های سازگار می‌سازد و `patch_android.py` بخش Kotlin، Manifest و Gradle را به آن اضافه می‌کند.

## راه‌اندازی

پیش‌نیاز: Node.js ‏18+، JDK ‏17، Android Studio (برای SDK) و اینترنت (برای بار اول).

```bash
cd AzanGo
./setup.sh          # npm install + npx cap add android + الحاق Kotlin + cap sync
```
سپس پوشه `android/` را در Android Studio باز کنید (File ▸ Open) و Gradle Sync را بزنید.
اگر `patch_android.py` پیام خطا داد، دو کار دستی لازم است: در `android/build.gradle` خط
`classpath 'org.jetbrains.kotlin:kotlin-gradle-plugin:1.9.22'` را کنار classpath مربوط به Android Gradle Plugin اضافه کنید و در
`android/app/build.gradle` عبارت `apply plugin: 'kotlin-android'` و بلوک `android { kotlinOptions { jvmTarget = '17' } }` را بیفزایید.

## ساخت APK

**Debug** (برای نصب مستقیم روی گوشی):
```bash
./build-apk.sh     # خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```
یا در Android Studio: Build ▸ Build APK(s).

**Release**: در Android Studio: Build ▸ Generate Signed Bundle / APK ▸ APK، یک keystore بسازید (و آن را با رمز در جای امن نگه دارید) و `release` را انتخاب کنید.
بعد از هر تغییر در `www/` اجرا کنید: `npx cap sync android`.

## نصب روی گوشی

APK را منتقل کنید ▸ «نصب از منابع ناشناس» را برای همان برنامه (فایل‌منیجر/مرورگر) مجاز کنید ▸ نصب.

## فایل صوتی اذان (مشاری العفاسی و دیگران)

فایل صوتی داخل برنامه گنجانده نشده تا حقوق مالکیت رعایت شود. روش کار:
1. فایل اذان را از منبعی تهیه کنید که **صراحتاً** اجازه استفاده شخصی/توزیع می‌دهد، یا فایلی که خودتان به‌صورت قانونی تهیه کرده‌اید. شرایط استفاده منبع را بررسی کنید.
2. فایل (mp3/m4a/ogg/wav) را با USB، بلوتوث یا مرورگر روی گوشی بریزید.
3. در برنامه: تنظیمات ▸ مؤذن و فایل صوتی ▸ «مشاری العفاسی» ▸ «انتخاب فایل». فایل داخل حافظه خصوصی برنامه کپی می‌شود، پس حذف فایل اصلی مشکلی ایجاد نمی‌کند.
4. «آزمایش» را بزنید. مؤذن دیگر: «افزودن مؤذن دلخواه» و همین مراحل.

تا وقتی فایلی انتخاب نشود، صدای زنگ پیش‌فرض (Alarm) گوشی پخش می‌شود. فایل کامل پخش می‌شود و با پایان آن سرویس بسته می‌شود.

## اوقات شرعی

روش: مؤسسه ژئوفیزیک دانشگاه تهران (صبح ۱۷٫۷°، مغرب ۴٫۵°، عشا ۱۴°، عصر با ضریب سایه ۱)، با مختصات شهر. منطقه زمانی شهرهای ایران +۳:۳۰ ثابت است (ایران از ۱۴۰۱ ساعت تابستانی ندارد). برای مکان دیگر از «موقعیت دستی» استفاده کنید.
**پیش از اتکا، چند روز اوقات را با تقویم رسمی شهرتان مقایسه کنید**؛ اختلاف یکی‌دو دقیقه‌ای ممکن است (ارتفاع محل، تفاوت جدول‌ها). تقویم شمسی/قمری با Intl خود گوشی محاسبه می‌شود و قمری قابل اصلاح ±۲ روز است.

## چطور در پس‌زمینه کار می‌کند

- رابط، اوقات ۴۵ روز آینده را محاسبه و به Kotlin می‌دهد (هر بار باز شدن برنامه یا تغییر تنظیمات، دوباره).
- Kotlin همیشه **فقط یک آلارم** را آماده نگه می‌دارد (نزدیک‌ترین رویداد) با `AlarmManager.setAlarmClock`: دقیق، مقاوم در برابر Doze، بدون نیاز به مجوز «آلارم دقیق». هزینه آن: آیکن ساعت کوچک در نوار وضعیت.
- هنگام اذان، `AzanReceiver` ‏→ `AzanService` (Foreground Service با اعلان و دکمه «توقف اذان»). هر رویداد فقط یک بار پردازش می‌شود (ثبت `last`) تا اذان تکراری پخش نشود.
- بعد از ری‌استارت گوشی، به‌روزرسانی برنامه، تغییر ساعت یا منطقه زمانی، `BootReceiver` آلارم بعدی را از فهرست ذخیره‌شده دوباره می‌سازد.
- بستن از Recent Apps معمولاً آلارم‌ها را از بین نمی‌برد.
- مصرف باتری پایین است؛ هیچ پردازش دائمی یا Wake Lock دائمی وجود ندارد.

### محدودیت‌های واقعی (قول تضمینی نمی‌دهم)

- **Force Stop**: اگر کاربر از Settings ▸ Apps ▸ AzanGo ▸ «توقف اجباری» بزند، اندروید تمام آلارم‌ها و گیرنده‌ها را تا باز شدن دستی برنامه غیرفعال می‌کند. هیچ برنامه‌ای نمی‌تواند این را دور بزند. (بستن عادی از Recent Apps «Force Stop» نیست، اما برخی سازندگان آن را مثل Force Stop رفتار می‌کنند.)
- **سازندگان** (شیائومی/MIUI، هواوی، اوپو/ریل‌می، ویوو، سامسونگ، وان‌پلاس): بدون فعال کردن «شروع خودکار» و «بدون محدودیت باتری» ممکن است برنامه را ببندند. صفحه اعلان‌ها دکمه‌های لازم را دارد؛ راهنمای هر برند در سایت dontkillmyapp.com هست.
- اگر برنامه بیش از ۴۵ روز اصلاً باز نشود، فهرست رویدادها تمام می‌شود. برای سالمند بهتر است ماهی یک بار باز شود.
- صدا روی کانال **Alarm** پخش می‌شود؛ ولوم Alarm گوشی را بالا نگه دارید. حالت «مزاحم نشوید» ممکن است صدا را قطع کند.
- مجوز اعلان در اندروید ۱۳+ باید داده شود، وگرنه یادآوری قبل از اذان نمایش داده نمی‌شود (پخش اذان با سرویس همچنان انجام می‌شود، اما اعلان توقف دیده نمی‌شود).
- مجوز `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` برای نصب مستقیم APK مناسب است؛ گوگل‌پلی ممکن است برای انتشار آن را محدود کند.

## چک‌لیست تست روی گوشی (۱۰ دقیقه)

1. نصب ▸ باز کردن ▸ مجوز اعلان را بدهید.
2. انتخاب فایل صوتی ▸ «آزمایش» ▸ پخش کامل و دکمه «توقف اذان» در اعلان.
3. زمان یکی از اوقات را موقتاً با موقعیت دستی/ساعت نزدیک کنید یا تا اذان واقعی صبر کنید؛ برنامه را از Recent Apps ببندید و صفحه را قفل کنید.
4. گوشی را ری‌استارت کنید (بدون باز کردن برنامه) و دوباره بررسی کنید.
5. در گوشی‌های شیائومی/سامسونگ/…، تنظیمات باتری و شروع خودکار را انجام دهید.
